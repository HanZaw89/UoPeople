Notice

Cross-device sync

This site is static (GitHub Pages), so it has no server of its own to store your progress — by default your data is saved only in this browser's local storage, which is why it doesn't follow you when you switch browsers or devices. Connecting a private GitHub Gist gives it a real place to sync through. Use the same Token and same Gist ID on every browser/device you use this dashboard on.

How do I get a token?

On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under "Permissions" → "Account permissions", set Gists to Read and write. No repository access is needed. Copy the token (starts with github_pat_) and paste it above. It's stored only in this browser's local storage and sent directly from your browser to GitHub's API — never anywhere else.
